# ☕ Estudos Java — Lógica de Programação

Repositório com exercícios práticos desenvolvidos durante o aprendizado de Java, cobrindo desde tipos de dados até estruturas de coleções.

---

## 📁 Estrutura do Projeto

| Arquivo | Conteúdo |
|---|---|
| `Main.java` | Tipos primitivos e saída de dados |
| `OperadoresAritmeticos.java` | Operadores aritméticos na prática |
| `OperadoresLogicos.java` | If, else if, else, operador ternário e switch |
| `CastingConversoes.java` | Conversões entre tipos e casting |
| `EntradaSaidaDados.java` | Entrada de dados com Scanner |
| `While.java` | Estruturas de repetição: while, do while e for |
| `Array.java` | Declaração, inicialização e iteração de arrays |
| `EstudoArrayList.java` | ArrayList — add, get, remove, contains e clear |
| `EstudoHashMap.java` | HashMap — put, get, remove e iteração |
| `EstudoTreeMap.java` | TreeMap — ordenação, firstKey e lastKey |
| `PlantaCasa.java` | Classe com atributos e métodos |
| `Casa.java` | Criação de objetos e uso de métodos |

---

## 💡 Conceitos praticados

- Tipos primitivos (`int`, `double`, `char`, `boolean`)
- Operadores aritméticos e lógicos
- Estruturas condicionais (`if`, `else if`, `else`, `switch`)
- Operador ternário
- Estruturas de repetição (`while`, `do while`, `for`, `for each`)
- Entrada e saída de dados com `Scanner`
- Casting e conversões entre tipos
- Arrays
- Coleções: `ArrayList`, `HashMap`, `TreeMap`
- Orientação a objetos: classes, atributos e métodos
